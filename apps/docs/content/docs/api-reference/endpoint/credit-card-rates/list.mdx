---
title: "List Credit Card Rates"
description: "Retrieve current credit card rates, fees, and offer details."
---

## Endpoint

| Field        | Value                       |
| ------------ | --------------------------- |
| Method       | `GET`                       |
| Path         | `/api/v1/credit-card-rates` |
| Operation ID | `listCreditCardRates`       |

## Responses

| Status | Description                    |
| ------ | ------------------------------ |
| `200`  | Retrieve all credit card rates |
| `500`  | Server error                   |

This endpoint returns a comprehensive list of credit card rates and offers from most financial institutions and issuers in New Zealand. The data includes purchase, cash advance, and balance transfer rates, interest-free periods, and primary fees for various credit card products.

## Response Data

- Institution/issuer name and ID
- Plan name and ID
- Purchase interest rate (`purchaseRate`)
- Cash advance rate (`cashAdvanceRate`)
- Balance transfer rate and period (`balanceTransferRate`, `balanceTransferPeriod`)
- Interest-free period in months (`interestFreePeriodInMonths`)
- Primary card fee in NZD (`primaryFeeNZD`)

Reward program details, minimum credit limits, and other plan benefits are not returned as structured fields.

## Use Cases

- Credit Card Comparison Tools: Help users find the best credit card rates based on their spending habits
- Financial Advice Applications: Integrate credit card data into holistic financial planning tools
- Fee Comparison Tools: Help users compare interest-free periods and primary fees across issuers
- Balance Transfer Calculators: Create tools to help users find the best balance transfer offers
- Spending Analysis: Integrate credit card features with spending tracking applications

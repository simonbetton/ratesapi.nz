---
title: "List Personal Loan Rates"
description: "Retrieve current personal loan rates from New Zealand financial institutions."
---

## Endpoint

| Field        | Value                         |
| ------------ | ----------------------------- |
| Method       | `GET`                         |
| Path         | `/api/v1/personal-loan-rates` |
| Operation ID | `listPersonalLoanRates`       |

## Responses

| Status | Description                      |
| ------ | -------------------------------- |
| `200`  | Retrieve all personal loan rates |
| `500`  | Server error                     |

This endpoint returns a comprehensive list of personal loan rates from most financial institutions in New Zealand. The data includes interest rates, loan terms, and special conditions for various personal loan products including secured and unsecured options.

## Response Data

- Institution name and ID
- Product name and ID
- Interest rate for each product (`rate`)
- Plan label when available (`plan`, for example `Secured`) — a free-text string, not a structured secured/unsecured flag
- Condition notes when available (`condition`, for example an amount range or eligibility note) — also free text

The API does not return separate advertised/comparison rates, minimum/maximum loan duration, or fee fields. `plan` and `condition` can be `null` when the source listing does not provide them.

## Use Cases

- Loan Comparison Platforms: Create tools that help consumers find the most competitive personal loan rates
- Budgeting Applications: Integrate real-time loan data into financial planning and budgeting tools
- Debt Consolidation Tools: Help users find the best rates for consolidating existing debts
- FinTech Solutions: Power lending marketplaces with current personal loan options

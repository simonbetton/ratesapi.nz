This project is a Bun workspace with three apps. The root scripts run a task across every app, and each app keeps its own scripts in its `package.json`.

| App    | Path        | Runs on                 |
| ------ | ----------- | ----------------------- |
| `api`  | `apps/api`  | `http://localhost:8787` |
| `docs` | `apps/docs` | `http://localhost:3000` |
| `web`  | `apps/web`  | `http://127.0.0.1:3002` |

## Prerequisites

- [Bun](https://bun.sh/): The JavaScript runtime and package manager used by the project
- Git: For version control
- A text editor or IDE such as VS Code or WebStorm
- A Cloudflare account if you need remote D1 access or deployment

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/simonbetton/ratesapi.nz.git
cd ratesapi.nz
```

### 2. Install Dependencies

```bash
bun i
```

One install at the repository root covers every app.

### 3. Run Everything

```bash
bun run dev
```

This starts the API, docs, and web apps together. The API runs against a local D1 database. Each start creates any missing tables and adds sample data without overwriting rows you already have, so no Cloudflare account is needed.

## Working With One App

Use `--filter` with an app name to run a single app's script:

```bash
bun run --filter docs dev
```

### Remote D1 Data

To run the API against the remote development D1 database instead of local sample data, log in to Cloudflare and run:

```bash
bun run --filter api dev:remote
```

## Scraping Data

The project includes scripts to scrape rate data from interest.co.nz, which aggregates lending rates across New Zealand financial institutions. These scripts are located in the `apps/api/bin/` directory.

Available scraper scripts:

- `scrape-mortgage-rates.ts`: Fetches current mortgage rates
- `scrape-personal-loan-rates.ts`: Fetches personal loan rates
- `scrape-car-loan-rates.ts`: Fetches car loan rates
- `scrape-credit-card-rates.ts`: Fetches credit card rates

To run all scrapers against local D1:

```bash
bun run --filter api scrape:local
```

## Checks

Run the full local verification suite before opening a pull request:

```bash
bun run check
```

This runs Oxlint and Oxfmt, type checks every app, and runs the Bun tests. To build every app the way CI does:

```bash
bun run build
```

## Common Workflows

| Task | Files to start with |
| --- | --- |
| Add an endpoint | `apps/api/src/routes/`, `apps/api/src/models/`, `apps/api/test/api-contract.test.ts` |
| Update docs content | `apps/docs/content/docs/` |
| Update scraper behavior | `apps/api/bin/` and `apps/api/src/lib/schema.ts` |
| Change deployment | `apps/api/wrangler.toml`, `apps/docs/wrangler.toml`, `.github/workflows/` |
